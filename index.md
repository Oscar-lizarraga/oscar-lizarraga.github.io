### Flagship Project: Enterprise Logistics & Microservices Platform

[**SIAP: Distributed Multi-Service Logistics & Last-Mile Delivery Platform**](/pages/systems/siap_logistics_platform.md)  
A high-throughput, polyglot microservices ecosystem combining **.NET 8 Core (C#)**, **Golang**, **Python (Flask & FastAPI)**, and **PostgreSQL**. Features real-time mobile telemetry streaming from **Azure Cosmos DB**, atomic job scheduling with **MongoDB**, asynchronous headless **ePOD PDF generation**, and secure **Azure Blob Storage** integration behind an **Nginx API Gateway**.

---

### Case Study: High-Throughput Data Ingestion & Applied AI

[**Logistics ETL Pipeline with Self-Healing AI Remediation**](/pages/systems/self_healing_etl.md)  
An autonomous, dual-speed logistics ingestion microservice in **Go (Golang)** and **PostgreSQL** integrated with **Azure AI Foundry (LLMs)** and **Microsoft Graph API (SharePoint)**. Combines bare-metal binary streaming (>10,000 records/sec) with a cognitive fallback that autonomously diagnoses schema drift, physically restructures Excel workbooks in-memory, synthesizes missing status columns, and updates cloud files in-place preserving version history.
