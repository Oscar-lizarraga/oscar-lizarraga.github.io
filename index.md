### <span class="blue-title" style="color: #267CB9; font-weight: 400;">Offline-First Mobile Field Logistics & Computer Vision ePOD</span>

[Delivery APP | .NET MAUI blazor hybrid, Web Api, MongoDB, CosmoDB](/pages/systems/delivery_mobile_app.md)  
An offline-first last-mile delivery platform (Rigel v2.1) built with .NET 8 MAUI Blazor Hybrid (Profiled AOT), ASP.NET Core 8 Web API (v1–v3), SQLite (v8), Azure Cosmos DB (MongoDB API), and Azure Blob Storage. [Banking Application | Core Retail Banking, Credit Risk Underwriting & Distributed SQL Server](/pages/database/banking_application.md)  
An enterprise retail banking and credit risk underwriting platform built over a distributed Microsoft SQL Server database containerized with Docker across an isolated virtual network. Solves end-to-end banking governance across 12 normalized business entities: automated credit card prospect classification across 15 socioeconomic, employment, and credit-bureau indicators, a controlled 3-stage customer onboarding funnel (Prospect capture, Advisor underwriting approval, and Active Customer conversion), dual payment instrument lifecycle management (revolving Credit Cards with billing cycles and credit limits alongside PIN-authenticated Debit Cards), physical branch and ATM cash-vault liquidity tracking, and a segregated financial ledger separating inter-account wire transfers from security-code ATM cash withdrawals.
